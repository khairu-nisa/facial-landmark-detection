# facial-landmark-detection
Real-time facial landmark detection using Python, OpenCV and MediaPipe. Detects 468 key facial points (eyes, nose, lips, jawline) from images and webcam video. Useful for face alignment, expression analysis, drowsiness detection and AR filters. A beginner-friendly computer vision project with clean, easy-to-run code.
## Tech Used
Python, OpenCV, MediaPipe

## How to run

```bash
pip install -r requirements.txt
python main.py                      # webcam
python main.py --image photo.jpg    # image
```
